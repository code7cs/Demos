# Demos monorepo

GitHub: [code7cs/Demos](https://github.com/code7cs/Demos)

## Local path should be

```text
~/code/Demos/              ← git root
├── angular-demos/         ← Angular app
├── mock-app/
└── ...
```

## If your folder is still named wrong

Open **Ubuntu (WSL) terminal** and run:

```bash
bash ~/code/Demos/AngularProject2026/fix-demos-path.sh
```

Then in Cursor: **File → Open Folder →** `~/code/Demos`

## Run Angular app

```bash
cd ~/code/Demos/angular-demos
npm start
```
