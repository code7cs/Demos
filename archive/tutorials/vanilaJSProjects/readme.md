# Vanilla JavaScript Projects

Mini projects and exercises built with HTML, CSS, and JavaScript.

## Repository Layout

- `async-javascript/` contains runnable async exercises.
- `dom-projects/` contains browser-based DOM demos.
- `utilities/` contains reusable JavaScript helpers and standalone scripts.

## Async Exercises

Run the provided Promise solutions:

```bash
node async-javascript/promise-all/tests.js
node async-javascript/promise-race/tests.js
```

After implementing an exercise file, test it with:

```bash
node async-javascript/promise-all/tests.js exercise
node async-javascript/promise-race/tests.js exercise
```
